# Enjambre de Luciérnagas Digitales

Simulación interactiva de un enjambre de criaturas luminosas en 3D usando Three.js.

## Requisitos cumplidos

- Escena base (T1): cámara, luces, niebla, partículas, bosque nocturno.
- Modelo de agente (T2): clase `FireflyAgent` con animación de alas y brillo.
- Mínimo 5 agentes (12 en escena) con posiciones iniciales distintas.
- Movimiento autónomo: cada agente avanza en su dirección y rebota en los límites.

## Controles

- **Ratón**:
  - Arrastrar: rotar cámara.
  - Botón derecho + arrastrar: pan.
  - Rueda: zoom.

## Tecnologías

- Three.js (WebGL)
- JavaScript (ES6)

## Ejecución

1. Clonar repositorio.
2. Usar Live Server en VS Code o cualquier servidor HTTP.
3. Abrir `index.html`.
